## Что нужно

Rust ставится через [rustup](https://rustup.rs). Версию выбирать не нужно, потому что [`rust-toolchain.toml`](https://github.com/andreypfau/mcrs/blob/main/rust-toolchain.toml) закрепляет `nightly-2026-09-02`, и rustup скачает ее при первом вызове `cargo`. Он же добавит rustfmt, clippy, цели wasm32 и кодогенератор Cranelift, которым отладочная сборка компилирует большую часть крейтов workspace.

На Linux клиент работает и с Wayland, и с X11.

В качестве IDE подойдет RustRover или IntelliJ IDEA с плагином Rust. Корень репозитория открывайте как проект Cargo. Условия лицензии RustRover проверьте сами.

mcrs нужен официальный клиентский jar снапшота, но скачивать его вручную не придется. mcrs берет его из папки лаунчера или при первом запуске скачивает с Mojang в ту же папку, а потом проверяет SHA-1. Еще клиенту нужны файлы шрифтов и панорама главного меню, которые игра хранит вне jar. Их он берет из папки `assets/objects` лаунчера или скачивает с Mojang в эту папку и проверяет SHA-1 каждого файла.

Нативный клиент загружает определения блоков в фоне, поэтому окно может открыться до их готовности. Автоматическое подключение через `--connect` ждет этих определений. Веб-клиент по-прежнему загружает их синхронно.[^1057]

Чтобы запустить mcrs, Java не нужна. Oracle и инструменты, которые запускают ваниль, требуют версию Java из поля `java_version` в [`version.json`](https://github.com/andreypfau/mcrs/blob/main/assets/minecraft/version.json).

Нативный клиент проверили на Windows в release-сборке с GTX 1080, включая запуск и подключение к локальному серверу.[^1057] CI запускает проверки на Ubuntu 24.04, а профиль тестов по умолчанию пропускает GPU-тесты.

В каталоге `crates/` {fact('crates')} крейтов. Этот гайд не дает оценки времени первой сборки или места, которое она займет на диске.

## Cargo для тех, кто знает Gradle

| Gradle | Cargo |
|---|---|
| `settings.gradle` с подпроектами | Корневой `Cargo.toml` с `[workspace]`. В него входят пакеты из `crates/`, `tools/` и `examples/` |
| `build.gradle` проекта | `Cargo.toml` крейта |
| `./gradlew run` | `cargo run`. Для mcrs добавляйте `--release`, потому что отладочная сборка слишком медленная |
| `./gradlew build` | `cargo build` |
| `./gradlew test` | `cargo test`. В этом репозитории запускают `cargo nextest run` |
| Gradle wrapper закрепляет версию Gradle | `rust-toolchain.toml` закрепляет компилятор |
| Папка `build/` | Папка `target/` |
| Координаты Maven и версия | Имя крейта и версия либо git URL с `rev` |
| Lock-файл зависимостей | `Cargo.lock`, хранится в репозитории |
| Области `implementation` и `api` | `[dependencies]`. Области `api` нет, видны все `pub`-элементы |

Крейты не опубликованы на crates.io, поэтому свой код сейчас приходится держать в клоне репозитория или подключать mcrs по git-коммиту.[^321]
