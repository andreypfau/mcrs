Это единственная полная таблица статуса в документации, на других страницах показана ее часть. У каждой строки есть дата и либо проверка, которую можно запустить, либо раздел PERF.md.

## Что значат состояния

| Состояние | Значение |
|---|---|
| <Status state="works" /> | Это подтверждает тест, который можно запустить, или замер в PERF.md |
| <Status state="partial" /> | Часть работает, остальное описано в issue или PR |
| <Status state="wip" /> | В коде этого нет или оно не закончено, и на это есть issue |
| <Status state="undecided" /> | Решения пока нет. В этом состоянии загрузчик плагинов (jar, wasm, скрипты) |
| <Status state="declined" /> | Закрытое решение отвечает "нет" |

<Aside type="note" title="Запланировано - это направление">
Слово "запланировано" в issue задает направление. Срока у него нет, и это не обещание. Состояние issue тоже не говорит о состоянии кода. Закрытая issue не всегда значит "сделано", а часть возможностей уже есть в коде, хотя их issue еще открыты.
</Aside>

## Что не планируется

- Поддержка старых версий игры. mcrs работает с одной версией за раз.[^412]
- Датафиксеры (datafixers). Сохранение читается строго в целевой версии данных, а неизвестное поле вызывает явную ошибку.[^388]
- Фасад или крейт с Bukkit-подобным API.[^437] Это решение касается только фасада. По загрузчику плагинов в виде jar, wasm или скриптов решения пока нет.

## Как следить за ходом работы

Чтобы следить за проектом, читать код не обязательно.

- Вся работа видна в [репозитории на GitHub](https://github.com/andreypfau/mcrs).
- Чтобы следить за одной issue, откройте ее из таблицы и нажмите Watch справа. Нужен аккаунт GitHub, и при каждом изменении issue вам придет письмо.
- [Последние изменения в коде](https://github.com/andreypfau/mcrs/commits/main) и [релизы](https://github.com/andreypfau/mcrs/releases) тоже лежат на GitHub.
- Вопросы и отчеты о ходе работы есть в [Discord](https://discord.gg/ged3nMRzwG).
- Направление задают три issue: про библиотеку, про работу на многих нодах и про геймплей.[^180][^181][^182]
- Решения с причинами записаны в issue с меткой [`decision`](https://github.com/andreypfau/mcrs/issues?q=label%3Adecision).

Эту страницу мы вручную проверяем раз в месяц и при каждом новом теге.
