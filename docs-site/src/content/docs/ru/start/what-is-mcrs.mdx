## Набор крейтов, из которых собраны сервер и клиент

mcrs - это набор из {fact('crates')} крейтов на Rust для Minecraft Java Edition. Из них на Bevy ECS собраны сервер и клиент. ECS расшифровывается как entity component system. Мир в такой схеме хранится как данные в таблицах, а поведение описывают функции, их называют системами. Если системы работают с разными данными, планировщик Bevy запускает их параллельно.

Проект следует за одним снапшотом игры за раз. Сейчас это {fact('snapshot')}, значение записано в `assets/minecraft/version.json`. Совместимости со старыми версиями нет (<Status issue={412} />).

Репозиторий открыт с 2025-12-10, проект пока на раннем этапе.

## Что работает сегодня

- Генерация мира совпадает с настоящей игрой на эталонных дампах, элемент за элементом. Проверяются эталонные сиды и чанки, а не каждый возможный сид.
- Клиент рисует рельеф, небо, облака, свет и мобов. Все замеры сняты на одной машине, Apple M4 Max с macOS, и записаны в [PERF.md](https://github.com/andreypfau/mcrs/blob/main/PERF.md).
- Ванильный клиент того же снапшота может зайти на сервер в offline-режиме, писать в чат, менять режим игры и ломать блоки в креативе.

Полная таблица со ссылкой на issue для каждого недостающего куска есть на странице [Статус](/docs/ru/start/status/).

## Чего от mcrs не ждать

mcrs - не Paper. В нем нет ни Bukkit-подобного API, ни фасада, потому что их отклоняет решение <Status issue={437} />. Публичный интерфейс - сами крейты и плагины. Загрузчика плагинов в виде jar, wasm или скриптов тоже нет, и решения о нем пока нет. Сегодня свой код вы пишете как Rust-плагин для Bevy и собираете вместе с сервером, что ближе к Minestom, чем к Paper. Подробно об этом рассказывает страница [Это не Paper](/docs/ru/plugins/not-paper/).

mcrs не готов к продакшену. Сервер не сохраняет чанки (<Status issue={78} />), не поддерживает online mode (<Status issue={82} />) и слушает все сетевые интерфейсы без аутентификации.

mcrs - не лаунчер и не мод. Клиент - отдельное приложение на Rust. Текстуры и модели он читает из официального jar игры, а графики Mojang в репозитории нет.
