<Aside type="danger" title="Не открывайте порт в интернет">
У сервера нет аутентификации, поэтому любой, кто до него доберется, зайдет под любым ником, в том числе под ником оператора. Сервер слушает все сетевые интерфейсы (`0.0.0.0:25565`). Запускайте его только на своей машине или в доверенной локальной сети.
</Aside>

## Запустите сервер

```bash
cargo run --release
cargo run --release -- "<path to a world folder>"
```

Первая команда запускает сервер с новым миром. Вторая открывает готовое сохранение Java Edition, и версия данных у него должна совпадать со снапшотом игры ({fact('snapshot')}). Сохранения других версий не загружаются, датафиксеров нет (<Status issue={388} />).

На эталонной машине, Apple M4 Max с macOS, релизная сборка без папки мира доходит до состояния Playing за 0.77 с, это медиана трех прогонов. Здесь измерен запуск уже собранного бинарника, время сборки в это число не входит. Замер записан в [PERF.md](https://github.com/andreypfau/mcrs/blob/main/PERF.md#server-start).

## Зайдите ванильным клиентом

Нужен ванильный клиент того же снапшота, {fact('snapshot')}. Сервер объявляет себя в списке LAN-миров, а еще на него можно зайти по адресу `localhost:25565`. Сервер работает в offline-режиме.

## Что можно делать

- Писать в чат.
- Выполнять команды с клиента или из консоли сервера, которая читает стандартный ввод: `/gamemode`, `/tp`, `/summon pig`, `/time`, `/fill`.
- Ломать блоки в креативе. По умолчанию режим игры - креатив.
- Летать по сгенерированному миру и создавать мобов через `/summon`: свиней, коров, овец, куриц и зомби-свинолюдов.

Настройки сервер читает из переменных окружения, например `MCRS_PORT`, `MCRS_WORLD_SEED`, `MCRS_WORLD_PRESET` (`normal` или `flat`) и `MCRS_DEFAULT_GAMEMODE`. Полный список есть в [`server_settings.rs`](https://github.com/andreypfau/mcrs/blob/main/crates/mcrs_minecraft_server_settings/src/server_settings.rs).

## Измененные блоки не сохраняются

Сервер не пишет измененные чанки на диск, поэтому каждый сломанный блок пропадает, когда сервер останавливается (<Status issue={78} />). Игроки сохраняются при штатном выключении (<Status pr={624} state="works" />). Штатное выключение, которое сохраняет еще и мир, отслеживается в <Status issue={169} />.

Ожидаемый вывод консоли и чек-лист первого запуска пока не написаны. За этими подробностями идите в README.
