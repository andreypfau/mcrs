<Aside type="danger" title="Не открывайте порт в интернет">
У сервера нет аутентификации, поэтому любой, кто до него доберется, зайдет под любым ником, в том числе под ником оператора. Сервер слушает все сетевые интерфейсы (`0.0.0.0:25565`). Запускайте его только на своей машине или в доверенной локальной сети.
</Aside>

## Запустите сервер

```bash
cargo run --release
cargo run --release -- "<path to a world folder>"
```

Первая команда запускает сервер с новым миром. Вторая открывает готовое сохранение Java Edition, и версия данных у него должна совпадать со снапшотом игры ({fact('snapshot')}). Сохранения других версий не загружаются, датафиксеров нет.[^388]

## Зайдите ванильным клиентом

Нужен ванильный клиент того же снапшота, {fact('snapshot')}. Сервер объявляет себя в списке LAN-миров, а еще на него можно зайти по адресу `localhost:25565`. Сервер работает в offline-режиме.

## Что можно делать

- Писать в чат.
- Выполнять команды из консоли сервера, которая читает стандартный ввод: `/gamemode`, `/tp`, `/summon pig`, `/time`, `/fill`. С клиента для них нужны права оператора. Вход с той же машины их не дает, поэтому после входа введите в консоли `op <ник>` или впишите игрока в `ops.json` в рабочей папке сервера и перезапустите его: сервер читает файл только при старте.[^pr933] Правила описаны в разделе [Кто становится оператором](/docs/ru/server/connections/#кто-становится-оператором).
- Ставить и ломать блоки. По умолчанию режим игры - креатив. Копать можно и в режиме выживания, но инструмент пока копает не быстрее пустой руки. Сломанный блок роняет предметы, их можно подобрать.
- Летать по сгенерированному миру и создавать мобов через `/summon`: свиней, коров, овец, куриц и зомби-свинолюдов.

Настройки сервер читает из переменных окружения, например `MCRS_PORT`, `MCRS_WORLD_SEED`, `MCRS_WORLD_PRESET` (`normal` или `flat`) и `MCRS_DEFAULT_GAMEMODE`. Полный список есть в [`server_settings.rs`](https://github.com/andreypfau/mcrs/blob/main/crates/mcrs_minecraft_server_settings/src/server_settings.rs).

## Измененные блоки сохраняются

Сервер записывает измененные чанки обратно в файлы регионов из папки мира каждые 6000 тиков, поэтому сломанный блок переживает перезапуск. Штатное выключение, первое нажатие Ctrl+C, сохраняет мир и игроков перед выходом сервера.[^pr624] Без папки мира на диск ничего не попадает.

Ожидаемый вывод консоли и чек-лист первого запуска пока не написаны. За этими подробностями идите в README.

[^388]: <Status issue={388} /> Решение о том, что сохранения читаются строго в целевой версии данных, без датафиксеров.
[^pr624]: <Status pr={624} state="works" /> Сервер отключает и сохраняет каждого игрока перед тем, как выключение завершится.
[^pr933]: <Status pr={933} state="works" /> Бинарник сервера дает права оператора только тем игрокам, которых называет `ops.json` или команда `op`.
