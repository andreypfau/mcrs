<Aside type="danger" title="Не открывайте порт в интернет">
У сервера нет аутентификации: любой, кто до него доберется, зайдет под любым ником, в том числе под ником оператора. Он слушает все сетевые интерфейсы (`0.0.0.0:25565`). Запускайте его только на своей машине или в доверенной локальной сети.
</Aside>

## Запуск

```bash
cargo run --release
cargo run --release -- "<path to a world folder>"
```

Первая команда запускает сервер с новым миром. Вторая открывает готовое сохранение Java Edition, у которого версия данных совпадает со снапшотом игры {fact('snapshot')}. Сохранения других версий не загружаются, датафиксеров нет (<Status issue={388} />).

На эталонной машине релизная сборка без папки мира доходит до состояния Playing за 0.77 с (медиана трех прогонов, Apple M4 Max, macOS, [PERF.md](https://github.com/andreypfau/mcrs/blob/main/PERF.md#server-start)). Это время запуска уже собранного бинарника, а не время сборки.

## Подключение

Нужен ванильный клиент того же снапшота, {fact('snapshot')}. Сервер появляется в списке LAN-миров, а еще можно зайти по адресу `localhost:25565`. Сервер работает в offline-режиме.

## Что можно делать

- Писать в чат.
- Выполнять команды с клиента или из консоли сервера, которая читает стандартный ввод: `/gamemode`, `/tp`, `/summon pig`, `/time`, `/fill`.
- Ломать блоки в креативе. Режим игры по умолчанию креатив.
- Летать по сгенерированному миру и создавать мобов через `/summon`: свиней, коров, овец, куриц и зомби-свинолюдов.

Настройки читаются из переменных окружения, например `MCRS_PORT`, `MCRS_WORLD_SEED`, `MCRS_WORLD_PRESET` (`normal` или `flat`) и `MCRS_DEFAULT_GAMEMODE`. Полный список - в [`server_settings.rs`](https://github.com/andreypfau/mcrs/blob/main/crates/mcrs_minecraft_server_settings/src/server_settings.rs).

## Что не сохраняется

<Aside type="caution" title="WIP">
Измененные чанки на диск не пишутся, поэтому каждый сломанный блок пропадает при остановке сервера: <Status issue={78} />. Игроки сохраняются при штатном выключении (<Status pr={624} state="works" />), а штатное выключение, которое сохраняет еще и мир, - это <Status issue={169} />.
</Aside>

Ожидаемый вывод консоли и чек-лист первого запуска пока не написаны. Подробности смотрите в README.
