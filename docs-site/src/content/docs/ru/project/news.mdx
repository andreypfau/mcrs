Каждая запись отвечает на три вопроса: что влито, что изменилось для тех, кто пишет плагины (пометка "Breaking", когда старый код перестает компилироваться), и чего еще нет. Новые записи сверху.

Последнему тегу 27 дней, и после него влито 152 PR. Поэтому первая запись покрывает работу, у которой еще нет тега.

## После v0.5.8 (тега пока нет)

С 2026-10-14 по 2026-11-10: 870 коммитов и 152 влитых PR от 6 авторов. 121 PR - от andreypfau, 31 - от пяти других людей.

Что влито, в нескольких строках:

- Миры тикают параллельными ячейками за потоком-мультиплексором (muxer) и общим слоем данных (<Status pr={646} state="works" />).
- Серверные мобы с параллельной стадией ИИ, отрисовка мобов в клиенте и бенчмарк на 50 000 свиней (<Status pr={651} state="works" />).
- Физика сущностей, проверки движения и симуляция блоков (<Status pr={648} state="works" />); очереди тиков блоков и событий блоков (<Status pr={477} state="works" />).
- Баны игроков и белый список по их спецификациям (<Status pr={637} state="works" />, <Status pr={635} state="works" />); отключение и сохранение каждого игрока перед остановкой (<Status pr={624} state="works" />); разрушение блоков в творческом режиме (<Status pr={643} state="works" />).
- Лендинг mc.rs с переключателем языка (<Status pr={629} state="works" />, <Status pr={633} state="works" />) и проверка компиляции клиента под `wasm32` в CI (<Status pr={622} state="works" />).
- Исправлен читатель VarInt и VarLong: теперь он отвергает биты вне диапазона (<Status pr={653} state="works" />).
- NBT в двух кодировках Bedrock, little-endian для хранения и varint для сети, рядом с кодировкой Java (<Status pr={679} state="works" />).
- Новый крейт `mcrs_minecraft_text_flatten` заполняет переводы в плоском тексте. Переведенная причина отключения теперь показывает свой fallback или ключ, а не пустую строку (<Status pr={680} state="works" />).
- Спецификация ломания блоков в режиме выживания, снятая с ванильного сервера (<Status pr={686} state="works" />).
- CI гоняет свои pull request одной задачей на собственном раннере, а pull request из форков на машинах GitHub, и правка только в `docs/` ничего не собирает (<Status pr={691} state="works" />). Cargo один раз собирает features для всего workspace (<Status pr={685} state="works" />).
- `AGENTS.md`, скиллы и правила по путям для агентов, которые пишут код (<Status pr={687} state="works" />, см. [Как внести вклад](/docs/ru/contributing/#работа-с-агентом)); метаданные для поисковиков, `robots.txt` и sitemap для лендинга (<Status pr={684} state="works" />).

Breaking для авторов плагинов (Rust, компилируются в сервер):

- `MinecraftServerPlugin` стал группой плагинов `MinecraftServerPlugins` с плагинами вроде `ServerCorePlugin`, `DimensionWorldsPlugin`, `WorldGenPlugin` и `ServerNetworkPlugin`. Любой из них можно отключить или заменить (<Status pr={551} state="works" />). Затем плагины движка переехали в новый крейт `mcrs_minecraft_engine_server`, а `mcrs_minecraft_server` хранит группу для ванили (<Status pr={592} state="works" />).
- Ни один крейт библиотеки больше не читает окружение или рабочий каталог ради настроек. Операторы теперь задаются полем `ops` плагина, а настройки клиента - ресурсом `Knobs` (<Status pr={548} state="works" />). См. [Переменные окружения](/docs/ru/reference/env-vars/).
- `Text::to_legacy_lossy` удален. Вместо него `plain_text` или `legacy_text` из `mcrs_minecraft_text_flatten`, которые принимают еще и `Language` (<Status pr={680} state="works" />).
- У методов чтения и записи в `mcrs_minecraft_nbt` больше нет суффикса `_be`: вместо `get_u8_be` теперь `get_u8` (<Status pr={679} state="works" />).

Новое для авторов плагинов:

- Плагин может добавлять плагины в мир каждого измерения или в один: `add_dimension_plugin` и `add_dimension_plugin_to` (<Status pr={552} state="works" />).
- Отменяемое событие чата: наблюдатель может остановить строку или заменить ее текст до рассылки (<Status pr={636} state="works" />, часть <Status issue={283} state="partial" />). События входа, выхода, движения и блоков не готовы.

Чего еще нет:

- Сохранения измененных чанков в файлы регионов (<Status issue={78} state="wip" />) и онлайн-режима (<Status issue={82} state="wip" />).
- Загрузчика плагинов вне сборки сервера. Решения по нему нет.
- Любых заявлений о скорости относительно другого сервера. Прогоны бенчмарка предварительные, см. [Производительность](/docs/ru/project/performance/).
