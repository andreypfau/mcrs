У mcrs есть собственный клиент, написанный на Rust с Bevy и wgpu. С ним можно летать по миру и смотреть на ландшафт, небо и мобов, но играть в выживание пока нельзя. Страница нужна игроку или наблюдателю, который хочет понять, что клиент умеет сегодня, чего не умеет и во сколько времени кадра и памяти обходится его дальний обзор.

## Что умеет клиент

| Возможность | Состояние |
|---|---|
| Ландшафт с блочными моделями и светом игры | Работает, в том числе цветной свет блоков |
| Небо, облака и туман окружения | Работает |
| Мобы | Работает для свиней, лягушек и игроков - типов, у которых есть модель в паке сущностей репозитория. Остальные типы мобов сервера клиент пока не рисует. Нативный клиент рисует игрока со скином из его профиля. Далеких мобов клиент рисует плоскими картинками, об этом рассказывает страница [Как клиент рисует](/docs/ru/client/rendering/) |
| Оверлей F3 со временем кадра и стадий | Работает |
| Чат с подсказками команд | Работает |
| Ломание блоков в творческом режиме и показ блока, на который наведен прицел | Работает |
| Титульный экран и локальные миры | Работает в нативном клиенте. При запуске клиент открывает титульный экран. Одиночная игра показывает миры из `saves` в игровой папке, создает новый мир, удаляет и открывает существующий, а Save and Quit to Title сохраняет мир и возвращает на титульный экран |
| Экран инвентаря | Работает. Клавиша E открывает его, предметы перекладываются мышью и клавишами. Клиент предсказывает каждый клик до ответа сервера, а следующие пакеты сервера перезаписывают предсказание. Вне экрана Q выбрасывает один предмет из выбранного стека, Control+Q - весь стек, а F меняет руки местами |
| Хотбар | Работает. Слот выбирают колесом мыши и клавишами 1-9, в режиме наблюдателя хотбара нет |
| Меню паузы и экраны настроек | Работает в нативном клиенте. Escape открывает меню паузы. В настройках графики можно на ходу менять дальность прорисовки, ограничение кадров, vsync и полноэкранный режим, а сами настройки клиент хранит в `options.json` в игровой папке |
| Вход на сервер mcrs или на встроенный | Работает. Ванильный клиент того же снапшота тоже может зайти на сервер mcrs в офлайн-режиме |

## Чего не хватает

| Возможность | Состояние |
|---|---|
| Звук | <Status issue={136} />. Клиент молчит |
| Частицы | <Status issue={137} /> |
| Погода (дождь, снег, молнии) | <Status issue={341} />. Сегодня дождь только притемняет солнце и луну |
| Экраны контейнеров и творческий инвентарь | Инвентарь игрока - это <Status issue={521} />. Экраны контейнеров - <Status issue={130} />. Клиент без GUI уже держит меню контейнера, которое открыл сервер, кликает в нем и закрывает его, но GUI такое меню пока не рисует. Творческий инвентарь - <Status issue={131} /> |
| Веб-сборка | <Status issue={344} />. Chrome рисует мир через WebGPU и через WebGL2. На WebGL2 браузер не рисует мобов, а время CPU и GPU веб-сборки еще не измеряли |
| Бинарные загрузки | Пока нет. Релизы запланированы, но на эту дату для них нет issue |

## Автор проверяет одну платформу

Автор проверяет клиент на одной платформе, Apple M4 Max с macOS и Metal. На Linux клиент собирается и с Wayland, и с X11, а один из контрибьюторов запускал его под Wayland, когда эту поддержку добавляли.[^826] Windows не подтвержден. CI на Ubuntu не запускает крейты, которым нужен wgpu, поэтому зеленый CI ничего не говорит об этих крейтах на Linux.

## Обзор в 96 колонок

По умолчанию клиент запрашивает обзор в 96 колонок. Колонка - это стопка секций размером 16x16x16 блоков. Это втрое больше, чем максимум ванили, равный 32. На таком обзоре кадр ограничивает GPU. Память на 96 колонках пока не ограничена.[^337] Если GPU или RAM мало, уменьшите дальность прорисовки в настройках графики или запустите клиент с меньшим `MCRS_VIEW` - это число колонок, которое он запрашивает.

## Чтобы запустить клиент, соберите его из исходников

Бинарных загрузок нет, поэтому клиент нужно собрать из исходников. Шаги короткие и лежат в репозитории, поэтому страница их не повторяет. Следуйте разделу [Quick start в README](https://github.com/andreypfau/mcrs#quick-start). Клиент стартует с титульного экрана и запускает собственный сервер для мира, который там выбрали. В игровой папке лежат миры (в `saves`), настройки и история команд. На macOS это `~/Library/Application Support/mcrs`, на Linux `$XDG_DATA_HOME/mcrs` или `~/.local/share/mcrs`, на Windows `%APPDATA%\mcrs`, а `MCRS_GAME_DIR` задает другую папку. Остальные переменные и параметры, которые читает клиент, описаны на странице [Переменные клиента](/docs/ru/client/env-vars/). Если передать аргументом папку мира из `saves`, этот мир будет выбран в списке. Текстуры и модели клиент читает из официального jar игры, потому что в репозитории нет графики Mojang.
