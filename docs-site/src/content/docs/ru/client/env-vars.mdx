Здесь перечислены переменные `MCRS_*` и настройки клиента, а также параметры, которые меняют только замеры. Переменные сервера и тестов описаны на странице [Переменные окружения](/docs/ru/reference/env-vars/).

<Aside type="caution" title="WIP">
Часть имен может измениться, потому что параметры клиента переезжают в поля плагинов.[^278]
</Aside>

## Клиент

Бинарник клиента собирает все переменные `MCRS_*` процесса и отрезает префикс. Этот код лежит в `crates/mcrs_minecraft_client/src/native.rs`. Если имя встречается дважды, берется первое значение. Если значение неверное, нативный клиент печатает его в stderr и не запускается. Исключение - переменные-переключатели: клиент печатает неверное значение и оставляет значение по умолчанию. Браузерная сборка берет те же имена из строки запроса в нижнем регистре, например `?time=6000`.

У клиента, собранного с `singleplayer`, есть встроенный сервер, и он тоже читает серверные переменные из таблицы выше, например `WORLD_SEED` и `WORLD_PRESET`.

| Переменная | По умолчанию | Что делает | Файл |
|---|---|---|---|
| `MCRS_SERVER` | нет | `host:port` сервера, к которому надо подключиться. Без нее сборка singleplayer открывает титульный экран и поднимает собственный сервер для выбранного мира. | `native.rs` |
| `MCRS_GAME_DIR` | папка данных платформы | Игровая папка: в ней лежат миры (в `saves`), `options.json`, `command_history.txt` и `ops.json` встроенного сервера. Без переменной клиент берет `~/Library/Application Support/mcrs` на macOS, `$XDG_DATA_HOME/mcrs` или `~/.local/share/mcrs` на Linux и `%APPDATA%\mcrs` на Windows. Если игровую папку найти не удалось, клиент не сохраняет ни настройки, ни историю команд. | `game_directory.rs` |
| `MCRS_USERNAME` | `Player` | Имя игрока. | `config.rs` |
| `MCRS_VIEW` | `96` | Дальность прорисовки в колонках, от 2 до 96. Приоритетнее файла настроек. | `config.rs` |
| `MCRS_OPTIONS` | `options.json` в игровой папке | Путь к JSON-файлу с полями `fov`, `fov_effect_scale`, `smooth_light`, `clouds`, `brightness`, `view_distance`, `gui_scale`, `sensitivity`, `vsync`, `fullscreen`, `max_framerate` и `improved_transparency`. Неизвестные поля дают ошибку. Если переменная не задана, клиент читает `options.json` из игровой папки, когда такой файл есть. Настройки, измененные в меню, нативный клиент записывает обратно в файл. | `options.rs` |
| `MCRS_FULLSCREEN` | файл настроек (выкл) | Занять весь дисплей. Приоритетнее файла настроек. Не действует, если задана `MCRS_RESOLUTION`. | `config.rs` |
| `MCRS_OPEN_TO_LAN` | выкл | Встроенный сервер слушает на всех интерфейсах и объявляет себя. Аутентификации нет, поэтому любой в сети может зайти под любым именем. | `config.rs` |
| `MCRS_GUI_SCALE` | файл настроек (`0`, авто) | Фиксированный масштаб GUI. Приоритетнее файла настроек и меню. | `config.rs` |
| `MCRS_HISTORY` | `command_history.txt` в игровой папке | Файл, в котором хранится история команд. | `config.rs` |
| `MCRS_VSYNC` | файл настроек (выкл) | Вертикальная синхронизация. По умолчанию выключена, чтобы время кадра оставалось читаемым. Приоритетнее файла настроек. | `config.rs` |
| `MCRS_OCCLUSION` | вкл | Тест окклюзии по пирамиде глубины. `0` рисует каждую группу, которая проходит пирамиду видимости (frustum) и граф пещер. | `config.rs` |
| `MCRS_CAVE` | вкл | Отсечение по графу пещер. | `config.rs` |
| `MCRS_CHUNK_MAP`, `MCRS_LIGHT_LEVELS` | выкл | Отладочные оверлеи. | `config.rs` |
| `MCRS_ASYNC` | половина ядер, не меньше 4 | Потоки асинхронного вычислительного пула (построение мешей, декодирование колонок, освещение). | `config.rs` |
| `MCRS_MESH`, `MCRS_MESH_FLIGHT` | 2048, 2048 (web: 32, 128) | Сколько секций построитель мешей берет за кадр и сколько задач может быть в работе одновременно. | `config.rs` |
| `MCRS_UPLOAD` | `4` | Бюджет загрузки на кадр, в МБ. | `config.rs` |
| `MCRS_ARENA` | 192,640,512 (web: 32,208,80) | Размеры арен в МБ для квадов, моделей и граней, в виде `quads,models,faces`. | `config.rs` |
| `MCRS_JAR_WORKERS` | по умолчанию крейта | Число воркеров загрузки в онлайн-тесте крейта клиентского JAR. | [`native.rs`](https://github.com/andreypfau/mcrs/blob/main/crates/mcrs_minecraft_client_jar/src/native.rs) |
| `MCRS_CERT` | нет | Хеш сертификата для веб-клиента, который подключается к серверу. Только веб-сборка. | `config.rs` |

## Параметры для замеров

Не задавайте переменные из этого раздела для обычной игры. Они намеренно меняют то, что клиент рисует или измеряет.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `MCRS_HOT` | выкл | Держит одно ядро CPU занятым, чтобы производительные ядра не снижали частоту. Время движка при этом получается в два-три раза короче. Это не настройка для игрока. |
| `MCRS_GPU_HOT` | нет | Сжигает столько рабочих групп GPU после кадра, чтобы GPU оставался на полной частоте. |
| `MCRS_STATS` | нет | Секунды между строками F3, которые пишутся в лог при скрытом оверлее. |
| `MCRS_PROBE` | авто | `0` оставляет проходы GPU без замера, `1` замеряет каждый кадр. |
| `MCRS_RESOLUTION` | нет | Открывает окно размером ровно `<width>x<height>`. |
| `MCRS_LATENCY` | нет | На сколько изображений swapchain окно может убежать вперед. |
| `MCRS_MONITOR` | самый быстрый дисплей | `primary` открывает окно на основном дисплее. |
| `MCRS_CENSUS` | нет | Секунды между строками, где подсчитаны трассированные колонки по стадиям. |
| `MCRS_TRACY_PREVIEW` | выкл | Отправляет изображения кадров в Tracy. Стоит одного считывания (readback) за кадр. |
| `MCRS_CHUNK_GUARD`, `MCRS_LIGHT_GUARD` | выкл | `1` роняет клиент, когда игрок стоит в колонке, которой у клиента нет, `warn` только пишет в лог. `MCRS_LIGHT_GUARD` читается так же, но для света. |
| `MCRS_GPUTRACE` | нет | Путь для записи трассы GPU. |
| `MCRS_RASTER` | нет | Доля от 0 до 1 для растрового прохода. |
| `MCRS_DRAWS` | все | Список номеров отрисовок через запятую, которые надо оставить. |
| `MCRS_SKY` | все | Список проходов неба через запятую, которые надо рисовать: `disc,twilight,celestial,stars,clouds`. |
| `MCRS_FLY`, `MCRS_TURN` | нет | Скриптовый полет: игрок летит вперед на спринте с этой скоростью полета (способность по умолчанию 0.05) и один раз разворачивается через `MCRS_TURN` секунд. |
| `MCRS_TIME` | нет | Фиксирует все часы на заданном числе тиков. |
| `MCRS_POS`, `MCRS_LOOK`, `MCRS_SCREEN`, `MCRS_CURSOR` | нет | Стартовая позиция `x,y,z`, направление взгляда `yaw,pitch`, экран, который надо открыть (по умолчанию `title`, а также `none`, `inventory`, `pause`, `options`, `video` или `accessibility`), и позиция курсора для скриптовых снимков. |
| `MCRS_CAPTURE` | нет | Записать один скриншот в путь `.png` и выйти. |
| `MCRS_SCREENSHOT_DIR` | нет | Каталог для скриншотов. |
| `MCRS_SCENE_DIR`, `MCRS_SCENE_RECORD` | нет | Каталог для съемки сцены без окна и запись клиента ванили, из которой берутся сущности. |

Клиент читает их все в `crates/mcrs_minecraft_client/src/config.rs`, `dev/knobs.rs` и `scene_capture.rs`.
