На этой странице перечислены команды, которые сервер регистрирует сегодня, уровень прав для каждой и спецификация, где описано ее поведение. Корневых команд у сервера {fact('root_commands')}, а вместе с алиасом `tp` получается 21 имя. Большую часть регистрирует `VanillaCommandsPlugin` из `crates/mcrs_minecraft_command_vanilla`, остальные - `WorldCommandsPlugin` из `crates/mcrs_minecraft_command_world`. Список проверен по обоим файлам `plugin.rs` и по вызовам проверки прав у каждой команды на коммите `51d45c26a`. Если команда есть в ванили, но ее нет в списке, значит, здесь ее пока нет. Например, `setblock`, `give`, `say` и `stop` не зарегистрированы.

## Уровни прав

Каждой команде нужен уровень прав. Уровней пять, и они упорядочены так же, как в ванили. Их задает правило PERM-LEVEL-001 [спецификации command-permissions](https://github.com/andreypfau/mcrs/blob/main/docs/spec/command-permissions.md).

| Id | Название |
|---|---|
| 0 | `all` |
| 1 | `moderators` |
| 2 | `gamemasters` |
| 3 | `admins` |
| 4 | `owners` |

У игрока без прав оператора уровень `all`. У оператора тот уровень, который указан в `ops.json`, от 0 до 4, а команда `op` выдает уровень по умолчанию, то есть `owners`. Игрок, который заходит с той же машины, где работает сервер, становится оператором на время сессии. Каждой команде из следующей таблицы нужен уровень 2 или 3, поэтому запускать их могут только операторы.

## Ввод команд

Игрок вводит команды в чате. Сервер также читает свой стандартный ввод, и каждая строка выполняется в верхнем мире (overworld) как команда, источник которой - сам сервер. Если строк пришло много сразу, сервер растягивает их на несколько тиков и выполняет не больше 2000 строк за тик. Ответы попадают в лог сервера. Код находится в `ConsolePlugin` из `crates/mcrs_minecraft_console`.

## Для авторов плагинов

Команда - это обычный код Bevy-плагина. Плагин вызывает `add_command` с функцией сборки и функцией выполнения, а образец есть в обоих файлах `plugin.rs`. Команда может записывать эффекты, которые применяют другие системы, и еще команды порождают событие `CommandEvent`, которое можно отменить. Плагин нужно скомпилировать в сервер, потому что загрузчика для других плагинов нет и решения о нем пока тоже нет. Подробности есть на странице [Команды для плагинов](/docs/ru/plugins/commands/).
