Сервер регистрирует 20 корневых команд (21 имя с алиасом `tp`). Они приходят из двух плагинов: `VanillaCommandsPlugin` в `crates/mcrs_minecraft_command_vanilla` и `WorldCommandsPlugin` в `crates/mcrs_minecraft_command_world`. Список проверен по обоим файлам `plugin.rs` и по вызовам проверки прав у каждой команды на коммите `51d45c26a`. Команд, которые есть в ванили, но нет в этом списке, здесь пока нет. Например, `setblock`, `give`, `say` и `stop` не зарегистрированы.

## Уровни прав

Уровней пять, они упорядочены, как в ванили ([спецификация command-permissions](https://github.com/andreypfau/mcrs/blob/main/docs/spec/command-permissions.md), PERM-LEVEL-001).

| Id | Название |
|---|---|
| 0 | `all` |
| 1 | `moderators` |
| 2 | `gamemasters` |
| 3 | `admins` |
| 4 | `owners` |

Игрок, который не оператор, имеет уровень `all`. У оператора уровень тот, что указан в `ops.json`, от 0 до 4. Команда `op` выдает уровень по умолчанию, то есть `owners`. Игрок, который заходит с той же машины, становится оператором на время сессии. Каждой команде ниже нужен уровень 2 или 3, поэтому запускать их могут только операторы.

## Ввод команд

Игрок вводит команды в чате. Сервер также читает свой стандартный ввод: каждая строка выполняется как команда источника "сервер" в верхнем мире (overworld) (`ConsolePlugin` в `crates/mcrs_minecraft_console`). Пачка строк выполняется за несколько тиков, не больше 2000 строк за тик. Ответы идут в лог сервера.

## Для авторов плагинов

Команды - это код Bevy-плагинов: плагин вызывает `add_command` с функцией сборки и функцией выполнения (паттерн смотрите в обоих файлах `plugin.rs`), а команда может записывать эффекты, которые применяют другие системы. Команды также порождают отменяемое событие `CommandEvent`. Загрузчика для плагинов, которые не скомпилированы в сервер, нет, и решения о нем пока тоже нет. Подробности на странице [Команды для плагинов](/docs/ru/plugins/commands/).
