На этой странице перечислены переменные окружения `MCRS_*`, которые читают сервер, тесты, бенчмарки и сборка, и их значения по умолчанию. Сервер читает 16 из них. Переменные клиента описаны на странице [Переменные клиента](/docs/ru/client/env-vars/), в том числе параметры `dev`: `MCRS_MENU` для контейнера с образцами предметов и `MCRS_PLAY` для запуска мира, переданного аргументом.

Публичные поля плагинов клиента, в том числе `ClientRegistriesPlugin.defer_definitions`, описаны в разделе [Настройка библиотеки](/docs/ru/client/env-vars/#настройка-библиотеки).

## Сервер

Бинарник сервера `mcrs` читает переменные из таблицы ниже. Если переменная не задана, сервер берет значение по умолчанию. Если значение не удалось разобрать, сервер пишет предупреждение в лог и тоже берет значение по умолчанию. Для `MCRS_FORWARDING` и `MCRS_PROXY_UPSTREAMS` правило строже. Если их значение не разбирается, сервер не запускается. Не запускается он и тогда, когда `MCRS_FORWARDING` включена, а `MCRS_FORWARDING_SECRET` пуста. Как поставить сервер за прокси с этими тремя переменными, показано на странице [Подключения, прокси и операторы](/docs/ru/server/connections/). Код находится в `ServerSettings::read` из `crates/mcrs_minecraft_server_settings/src/server_settings.rs`, а вызывает его `src/main.rs`.

Переменная-переключатель включается значениями `on`, `1`, `true` и `yes` и выключается значениями `off`, `0`, `false` и `no`, регистр букв не важен. Пробелы по краям значения отбрасываются до разбора.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `MCRS_PORT` | `25565` | Порт, на котором сервер слушает. Сервер слушает на всех интерфейсах (`0.0.0.0`). Допустимо от 1 до 65535. |
| `MCRS_COMPUTE_THREADS` | по умолчанию плагина | Размер пула вычислительных потоков. Положительное число. |
| `MCRS_WORLD_SEED` | `0` | Сид мира, знаковый или беззнаковый 64-битный. Отрицательный сид сохраняет свои биты, как Java long. |
| `MCRS_WORLD_PRESET` | `normal` | Пресет мира, короткий (`flat`) или с пространством имен (`minecraft:flat`), приводится к нижнему регистру. |
| `MCRS_DEFAULT_GAMEMODE` | `creative` | Режим игры нового игрока: `survival`, `creative`, `adventure` или `spectator`. |
| `MCRS_MOB_AI` | вкл | Думают ли мобы. При выключении убирается плагин мозга мобов. |
| `MCRS_LAN_ANNOUNCE` | вкл | Объявляет ли сервер себя в локальной сети. Сервер, который слушает только loopback, никогда не объявляет себя. |
| `MCRS_COMPRESSION_THRESHOLD` | `256` | Размер пакета в байтах, начиная с которого пакеты сжимаются. Отрицательное число выключает сжатие. |
| `MCRS_ACCEPT_TRANSFERS` | выкл | Принимает ли сервер игроков, которых переносит (transfer) другой сервер. |
| `MCRS_ENABLE_STATUS` | вкл | Отвечает ли сервер на запросы статуса (пинг списка серверов). |
| `MCRS_HIDE_ONLINE_PLAYERS` | выкл | Скрывает ли статус имена игроков онлайн. Счетчики остаются. |
| `MCRS_FORWARDING` | выкл | Берет ли сервер UUID, имя, свойства профиля и адрес игрока от прокси Velocity (modern forwarding). Если включена, каждый вход должен идти через прокси. |
| `MCRS_FORWARDING_SECRET` | пусто | Секрет, общий с Velocity. Сервер берет значение как есть и не обрезает пробелы. |
| `MCRS_PROXY_UPSTREAMS` | пусто | Точные IP-адреса доверенных прокси через запятую. Соединение с такого адреса должно начинаться с заголовка PROXY protocol версии 1 или 2, и адрес клиента сервер берет из этого заголовка. Чтобы выключить эту функцию, не задавайте переменную. С пустым значением сервер не запускается. |
| `MCRS_LOCAL_PACKS` | нет | Имена папок дополнительных датапаков в `mcrs/datapacks` через запятую, например пак генерации мира для проверки. Они добавляются к `mcrs` и `beta`, а все локальные паки накладываются по имени папки: если два пака содержат один файл, побеждает имя, которое идет позже, независимо от порядка в переменной. Имя с разделителем пути отклоняется. |
| `MCRS_SPAWN` | нет | Где встает входящий игрок, `x,y,z` в блоках, поверх сохраненной позиции и спауна уровня. Игрок начинает в полете, если режим игры позволяет. Клиент читает ее для своего встроенного сервера. |

<Aside type="caution" title="Нет аутентификации">
Онлайн-режима у сервера пока нет.[^82] Он слушает `0.0.0.0:25565`, и любой, кто подключился, может взять любое имя игрока. Не открывайте порт в интернет.
</Aside>

Сервер также читает `ops.json`, `whitelist.json` и файлы банов из рабочего каталога. Это файлы, поэтому в таблице их нет.

## Тесты, бенчмарки и сборка

| Переменная | Кто использует | Что делает |
|---|---|---|
| `MCRS_BLESS` | тесты мешей, раскладок шейдеров рендера, моделей сущностей и анимации сущностей | `1` перезаписывает сгенерированные или ожидаемые файлы. Тесты моделей и анимаций принимают любое заданное значение; тестам мешей и раскладок шейдеров нужно ровно `1`. Без переменной устаревшие файлы не проходят проверку. |
| `MCRS_JAR_WORKERS` | онлайн-тест загрузки крейта клиентского JAR | Число воркеров загрузки, по умолчанию 4. На число воркеров бинарника клиента не влияет. |
| `MCRS_CLIENT_JAR` | тест отрисовки сущностей | Путь к клиентскому JAR. |
| `MCRS_VANILLA_SERVER_JAR`, `MCRS_SCENE_CLIENT`, `MCRS_SCENE_ENTITIES` | тест `scene_frames` клиента | Серверный JAR, другой бинарник клиента и источник сущностей сцены: `summon`, `record` или `skip` (по умолчанию). |
| `MCRS_MOLANG_CORPUS`, `MCRS_GPU_FUZZ_PROGRAMS` | тесты Molang | Путь к файлу корпуса и число fuzz-программ (по умолчанию 10000). |
| `MCRS_BENCH_WORLD`, `MCRS_BENCH_AREA` | бенч `random_ticks_save` | Каталог сохраненного мира и `<dimension> <x> <z> <radius>`, чтобы загрузить только эту область. Координаты центра задаются в блоках, радиус в колонках. Без каталога мира бенч пропускает запуск. |
| `MCRS_BIN` | [`mob-bench/run.sh`](https://github.com/andreypfau/mcrs/blob/main/tools/mob-bench/run.sh) | Путь к бинарнику `mcrs`. Серверные переменные бенч задает сам. |
| `MCRS_VANILLA_SERVER` | [`vanilla-server/run.sh`](https://github.com/andreypfau/mcrs/blob/main/tools/vanilla-server/run.sh) | Адрес vanilla-сервера, который скрипт передает тесту подключения `mcrs`. |
| `MCRS_DRAW_ONLY`, `MCRS_GPU_HOT`, `MCRS_SPLIT_DRAW` | пример `stress_field` отрисовки сущностей | Рисовать только `full_rigs` или `impostors`, число рабочих групп для удержания GPU (по умолчанию 16384) и разделение отрисовки на два прохода. |
| `MCRS_COMMIT_HASH` | время сборки сетевого крейта | Хеш коммита, который сообщает сервер. Крейт читает его через `option_env!` во время сборки, поэтому значение во время работы ни на что не влияет. |

[^82]: <Status issue={82} /> Отслеживает онлайн-режим: шифрование и аутентификацию сессии.
