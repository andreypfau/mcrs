Эта страница - справочная таблица для тех, кто знает Paper, Velocity или Minestom. Найдите знакомое название, и строка покажет, что ближе всего к нему в mcrs и в каком это состоянии сегодня. Если слова "сущность" и "система" вам незнакомы, сначала прочтите [От объектов к данным](/docs/ru/plugins/mental-model/).

<Aside type="caution" title="Каждая строка - аналогия">
Ни одна строка не дает готовой замены, потому что Bukkit-подобного API в mcrs нет, как объясняет страница [Это не Paper API](/docs/ru/plugins/not-paper/). Строка со статусом wip - это запланированная возможность, на которую есть issue, но еще нет кода. У строки со статусом undecided нет ни issue, ни решения.
</Aside>

## Жизненный цикл

| JVM | mcrs | Состояние | Заметки |
|---|---|---|---|
| `JavaPlugin`, `onEnable` | `impl Plugin for X` с `fn build(&self, app: &mut App)` | <Status issue={279} /> | Как и в Minestom, свой `main` пишете вы, см. [src/main.rs](https://github.com/andreypfau/mcrs/blob/main/src/main.rs). Ни `plugin.yml`, ни отдельного jar нет |
| `onDisable` | Хука нет. Остановка идет через сообщение `ShutdownRequest` | <Status state="partial" doc="crates/mcrs_minecraft_engine_server/src/shutdown.rs" /> | Запрос отправляет код, который встраивает сервер. Обработчик сигналов не устанавливается |
| `depend:` и `softdepend:` | Группа плагинов: если плагину нужен другой, он падает в `build` и называет недостающий | <Status issue={279} /> | См. `MinecraftServerPlugins` в [lib.rs](https://github.com/andreypfau/mcrs/blob/main/crates/mcrs_minecraft_server/src/lib.rs) |
| Отключить встроенную часть | `server.disable::<SomePlugin>()` на группе плагинов | <Status issue={282} /> | Используется в [`main.rs`](https://github.com/andreypfau/mcrs/blob/main/src/main.rs), чтобы выключить мозг мобов |
| `/reload`, PlugMan | Нет. Код не перезагружается | <Status issue={316} /> | Планируется только перезагрузка датапаков |
| NMS, CraftBukkit | Любой публичный крейт библиотечных слоев | <Status issue={437} /> | Фасада между вашим кодом и движком нет, поэтому эти крейты - одновременно NMS и API |
| Статический `Bukkit.getServer()` | Нет. `Res<T>`, `Query<..>` и `Commands` берутся как параметры системы | <Status issue={437} /> | Статический доступ отклонили |
| Зависимость от `paper-api` | Git-зависимость от крейтов mcrs | <Status issue={321} /> | Одна версия игры за раз, без обратной совместимости (<Status issue={412} />) |

## События

| JVM | mcrs | Состояние | Заметки |
|---|---|---|---|
| `Listener`, `@EventHandler` | Наблюдатель `app.add_observer(f)` с `f: fn(On<Event>)` или `MessageReader<M>` для буфера сообщений | <Status issue={283} /> | Публичные события есть только для чата. Наблюдатели пакетов есть как `Received<P>` |
| `setCancelled(true)` | Поле `cancelled` события, которое меняет наблюдатель с параметром `mut` | <Status pr={636} state="partial" /> | Только `PlayerChatEvent`. Общий механизм с откатом предсказания клиента - это <Status issue={283} /> |
| `AsyncChatEvent` | `PlayerChatEvent { player, text, cancelled }` | <Status pr={636} state="works" /> | `text` - компонент `Text`, а не `String`. Событие срабатывает до рассылки |
| `EventPriority` | Порядок систем: `.before()`, `.after()`, `SystemSet`, например `TickSet` | <Status issue={323} /> | У наблюдателей приоритета нет. Неупорядоченный конфликт ломает тест |
| `PlayerJoinEvent`, `PlayerQuitEvent` | Внутренние сообщения шины `InboundPlayerSpawn` и `InboundPlayerDespawn` | <Status issue={283} /> | Публичного события пока нет. Публичные события входа и выхода запланированы |
| `BlockBreakEvent`, `BlockPlaceEvent` | Внутреннее сообщение `BlockActionRequest` | <Status issue={283} /> | Публичные отменяемые события запланированы |
| `ProtocolLib`, слушатели пакетов | `On<Received<P>>` над типизированными игровыми пакетами | <Status state="partial" /> | Типизирована примерно половина пакетов, см. README. Единый путь типизированного приема: <Status issue={57} /> |
| Дерево `EventNode` в Minestom | Дерева событий нет, есть только наблюдатели и расписания Bevy | <Status state="undecided" /> | Issue нет. Этот паттерн не копируйте |

## Планировщик

| JVM | mcrs | Состояние | Заметки |
|---|---|---|---|
| `runTaskTimer` | Система в `FixedUpdate`, по умолчанию 20 тиков в секунду (`DEFAULT_TPS`) | <Status state="works" doc="crates/mcrs_minecraft_engine_server/src/runner.rs" /> | Состояние храните в ресурсе или `Local<T>`. Планированием занимается Bevy, собственного планировщика в mcrs нет |
| `runTaskLater` | Счетчик или таймер в ресурсе или компоненте, либо `Res<Time<Fixed>>` | <Status state="works" /> | Пишется вручную, готовых хелперов нет |
| `runTask` для возврата в главный поток | Не нужен. Главного потока в смысле Bukkit нет | <Status issue={357} /> | См. [От объектов к данным](/docs/ru/plugins/mental-model/) |
| `runTaskAsynchronously` | Пулы задач Bevy есть, но документированного паттерна для плагинов нет | <Status state="partial" /> | Issue нет. Параллельность обеспечивает планировщик |

| Сохранение мира, `world.save()` | Нет. Чтение Anvil работает, запись - нет | <Status issue={78} /> | Сервер не сохраняет чанки |
| Boss bar | Нет | <Status issue={247} /> | |
| Scoreboard | Нет. Scoreboard упоминает только запланированный владелец глобального состояния | <Status issue={154} /> | Issue про scoreboard нет, и кода мы не нашли |
