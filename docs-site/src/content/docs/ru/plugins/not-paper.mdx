## Короткий ответ

Плагин для Paper на mcrs не заработает. Bukkit-подобного API и крейта-фасада нет, так решено в <Status issue={437} state="declined" />. Загрузчика плагинов (jar, wasm, скрипты) сегодня тоже нет. По загрузчику нет ни issue, ни решения, поэтому "никогда" мы не говорим. JVM-код в сервер не загрузить, ни Java, ни Kotlin.

Сегодня нужно написать Bevy-плагин на Rust, добавить его рядом с плагинами сервера в собственном `main` и собрать один бинарник. Модель ближе к [Minestom](https://minestom.net/) (сервер как библиотека, `main` пишете вы), чем к Paper (готовый сервер и jar-файлы в `plugins/`). Направление описано в <Status issue={180} state="wip" />.

<Aside type="caution" title="Ранний WIP">
Публичный API библиотеки не стабилен. Целевая версия игры одна (`26.4-snapshot-7`), обратной совместимости нет, см. <Status issue={412} state="declined" />.
</Aside>

## А есть ли X?

| Привычка из Paper | В mcrs |
|---|---|
| `plugin.yml`, jar в `plugins/` | Нет. Код компилируется в бинарник сервера |
| Статический `Bukkit.getServer()` | Нет, отклонено в <Status issue={437} state="declined" />. Данные приходят как параметры системы |
| Стабильный API с версиями | Нет. Интерфейс - публичные крейты и плагины, версии нестабильны |
| `/reload` и горячая перезагрузка кода | Нет. Перезагрузка датапаков в планах, <Status issue={316} state="wip" /> |
| Скриптинг (Lua, JS) | Issue нет, решения нет |
