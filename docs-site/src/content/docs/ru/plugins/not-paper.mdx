Плагин, написанный для Paper, на mcrs не заработает. Эта страница для тех, кто пришел из Paper или Bukkit. Она рассказывает, чем здесь заменяется работа с API плагинов, что уже работает и чего пока нет.

В mcrs нет ни Bukkit-подобного API, ни крейта-фасада, и это решение проекта.[^437] Загрузчика плагинов сегодня тоже нет, поэтому сервер не умеет загружать jar, wasm-модуль или скрипт, и JVM-код на Java или Kotlin внутри него не запустить. По загрузчику никто не открывал issue и не принимал решения, поэтому слова "никогда" на этой странице нет.

Сегодня вы пишете Bevy-плагин на Rust, добавляете его рядом с плагинами сервера в собственном `main` и собираете один бинарник. Это ближе к [Minestom](https://minestom.net/), где сервер - библиотека, а `main` пишете вы, чем к Paper, где вы получаете готовый сервер и кладете jar-файлы в `plugins/`. Направление проекта - mcrs как библиотека, от прокси до полного сервера.[^180]

<Aside type="caution" title="Ранний WIP">
Публичный API библиотеки не стабилен. mcrs в каждый момент поддерживает одну версию игры (<code dir="auto">{fact('snapshot')}</code>) и не сохраняет обратную совместимость.[^412]
</Aside>

## Что работает сегодня

В таблице то, что ваш код уже может делать, и issue или pull request, который стоит за каждой строкой.

| Что нужно | Состояние | Где |
|---|---|---|
| Убрать или заменить часть сервера | Сервер - группа плагинов, и ее участников можно отключать | <Status issue={279} /> |
| Добавить свой код во все измерения или в одно | `add_dimension_plugin` и `add_dimension_plugin_to` | <Status issue={280} /> |
| Ванильный геймплей как отключаемые плагины | Сделано | <Status issue={282} /> |

Точка входа - [src/main.rs](https://github.com/andreypfau/mcrs/blob/main/src/main.rs). Он создает приложение и добавляет `MinecraftServerPlugins`, [группу плагинов](https://github.com/andreypfau/mcrs/blob/main/crates/mcrs_minecraft_server/src/lib.rs) сервера.

## Привычки из Paper, которые не переносятся

| Привычка из Paper | В mcrs |
|---|---|
| `plugin.yml`, jar в `plugins/` | Нет. Ваш код компилируется в бинарник сервера |
| Статический `Bukkit.getServer()` | Нет, отклонено в <Status issue={437} />. Система получает данные как параметры |
| Стабильный API с версиями | Нет. Вы собираетесь с публичными крейтами и плагинами, а их версии нестабильны |
| `/reload` и горячая перезагрузка кода | Нет. Перезагрузка датапаков запланирована в <Status issue={316} /> |
| Скриптинг (Lua, JS) | Issue нет, решения нет |

Полная таблица соответствий есть на странице [Paper и Minestom в терминах mcrs](/docs/ru/plugins/paper-to-mcrs/), а состояние каждой области показано на странице [Статус](/docs/ru/start/status/).
