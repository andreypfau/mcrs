mcrs - это Minecraft Java Edition на Rust поверх Bevy ECS: сервер, клиент и 122 крейта, из которых они собираются.

<Aside type="caution" title="Ранний WIP">
Проект в активной разработке, поэтому многого пока нет: сохранения мира, online mode, большей части геймплея. Мир и клиент уже запускаются.
</Aside>

## Почему mcrs

mcrs - не Java-сервер, переписанный на Rust. Проект заново решает, как должна быть устроена игра, и начинает с движка. Подробнее: [Почему mcrs: новое устройство, а не переписка](/docs/ru/start/philosophy/).
