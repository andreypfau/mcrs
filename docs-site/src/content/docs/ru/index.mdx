mcrs - это Minecraft Java Edition на Rust поверх Bevy ECS. В проекте есть сервер, клиент и {fact('crates')} крейта, из которых они собираются.

<Aside type="caution" title="Ранний WIP">
Проект в активной разработке, и многого пока нет, в том числе сохранения мира, online mode и большей части геймплея. Мир и клиент уже запускаются.
</Aside>

## Почему mcrs

mcrs - не Java-сервер, переписанный на Rust. Проект заново решает, как должна быть устроена игра, и начинает с движка. Каждое из этих решений объясняет страница [Почему mcrs: новое устройство, а не переписывание](/docs/ru/start/philosophy/).

## Что готово сейчас

Генерация мира совпадает с настоящей игрой на эталонных дампах, и клиент этот мир рисует. Чанки не сохраняются, online mode нет.[^78][^82] Мы проверили это 2026-11-10 на коммите `3540f457b`, снапшот игры {fact('snapshot')}. Полная таблица есть на странице [Статус](/docs/ru/start/status/).

Задать вопрос и почитать отчеты о ходе работы можно в [Discord](https://discord.gg/ged3nMRzwG).
