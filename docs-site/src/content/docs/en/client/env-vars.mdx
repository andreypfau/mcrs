This page lists the client's `MCRS_*` variables and options, plus the knobs that only change measurements. The variables of the server and the tests are on [Environment variables](/docs/en/reference/env-vars/).

<Aside type="caution" title="WIP">
Some names here may change, because the client knobs move into plugin fields.[^278]
</Aside>

## Client

The client binary collects every `MCRS_*` variable of the process and removes the prefix. The code is in `crates/mcrs_minecraft_client/src/native.rs`. If a name appears twice, the first value counts. When a value is bad, the native client prints it to stderr and refuses to start. An on/off variable is the exception: the client prints the bad value and keeps the default. The browser build takes the same names from the query string in lower case, for example `?time=6000`.

A client built with `singleplayer` has an integrated server, and that server also reads the [server variables](/docs/en/reference/env-vars/#server), such as `WORLD_SEED` and `WORLD_PRESET`.

| Variable | Default | What it does | File |
|---|---|---|---|
| `MCRS_SERVER` | none | `host:port` of a server to join. Without it, a singleplayer build opens the title screen and hosts its own server for the world you pick. | `native.rs` |
| `MCRS_GAME_DIR` | the data folder of the platform | The game directory, which holds the worlds in `saves`, `options.json`, `command_history.txt` and the `ops.json` of the integrated server. Without the variable the client takes `~/Library/Application Support/mcrs` on macOS, `$XDG_DATA_HOME/mcrs` or `~/.local/share/mcrs` on Linux and `%APPDATA%\mcrs` on Windows. When it finds no game directory, it keeps no options and no command history. | `game_directory.rs` |
| `MCRS_USERNAME` | `Player` | Player name. | `config.rs` |
| `MCRS_VIEW` | `96` | Render distance in columns, 2 to 96. Wins over the options file. | `config.rs` |
| `MCRS_OPTIONS` | `options.json` in the game directory | Path to a JSON file with `fov`, `fov_effect_scale`, `smooth_light`, `clouds`, `brightness`, `view_distance`, `gui_scale`, `sensitivity`, `vsync`, `fullscreen`, `max_framerate`, `improved_transparency` and `operator_items_tab`. Unknown fields are an error. Without the variable, the client reads `options.json` in the game directory if it exists. The native client writes the options you change in the menus back to the file. | `options.rs` |
| `MCRS_FULLSCREEN` | options file (off) | Take over a whole display. Wins over the options file. Ignored when `MCRS_RESOLUTION` is set. | `config.rs` |
| `MCRS_OPEN_TO_LAN` | off | The integrated server listens on every interface and announces itself. There is no authentication, so anyone on the network can join under any name. | `config.rs` |
| `MCRS_GUI_SCALE` | options file (`0`, auto) | Fixed GUI scale. Wins over the options file and the menu. | `config.rs` |
| `MCRS_HISTORY` | `command_history.txt` in the game directory | File that keeps the command history. | `config.rs` |
| `MCRS_VSYNC` | options file (off) | Vertical sync. Off by default so frame times stay readable. Wins over the options file. | `config.rs` |
| `MCRS_OCCLUSION` | on | Depth pyramid occlusion test. `0` draws every group that passes the frustum and cave graph. | `config.rs` |
| `MCRS_CAVE` | on | Cave graph culling. | `config.rs` |
| `MCRS_CHUNK_MAP`, `MCRS_LIGHT_LEVELS` | off | Debug overlays. | `config.rs` |
| `MCRS_ASYNC` | half the cores, at least 4 | Threads of the async compute pool (meshing, column decode, lighting). | `config.rs` |
| `MCRS_MESH`, `MCRS_MESH_FLIGHT` | 2048, 2048 (web: 32, 128) | Sections the mesher admits per frame, and how many jobs may be in flight. | `config.rs` |
| `MCRS_UPLOAD` | `4` | Upload budget per frame, in MB. | `config.rs` |
| `MCRS_ARENA` | 192,640,512 (web: 32,208,80) | Arena sizes in MB for quads, models and faces, as `quads,models,faces`. | `config.rs` |
| `MCRS_JAR_WORKERS` | crate default | Download workers in the online test of the client jar crate. | [`native.rs`](https://github.com/andreypfau/mcrs/blob/main/crates/mcrs_minecraft_client_jar/src/native.rs) |
| `MCRS_CERT` | none | Certificate hash for a web client joining a server. Web build only. | `config.rs` |

`operator_items_tab` defaults to `false`. Set it to `true` in the options file to allow the Operator Items tab when the player has operator permission. Controls has no button for this option yet.[^1033]

## Measurement knobs

Do not set the variables in this section for normal play. They change on purpose what the client draws or measures.

| Variable | Default | What it does |
|---|---|---|
| `MCRS_HOT` | off | Keeps one CPU core spinning so the performance cores do not clock down. Engine time then reads two to three times shorter. It is not a setting for players. |
| `MCRS_GPU_HOT` | none | Burns that many GPU workgroups after the frame so the GPU stays at speed. |
| `MCRS_STATS` | none | Seconds between F3 lines written to the log with the overlay hidden. |
| `MCRS_PROBE` | auto | `0` leaves GPU passes untimed, `1` times every frame. |
| `MCRS_RESOLUTION` | none | Opens a window of exactly `<width>x<height>`. |
| `MCRS_LATENCY` | none | Swapchain images the window may run ahead by. |
| `MCRS_MONITOR` | fastest display | `primary` opens the window on the primary display. |
| `MCRS_CENSUS` | none | Seconds between lines that count traced columns by stage. |
| `MCRS_TRACY_PREVIEW` | off | Streams frame images to Tracy. Costs a readback per frame. |
| `MCRS_CHUNK_GUARD`, `MCRS_LIGHT_GUARD` | off | `1` crashes the client when the player stands in a column the client does not hold, `warn` only logs. `MCRS_LIGHT_GUARD` reads the same way for light. |
| `MCRS_GPUTRACE` | none | Path for a GPU trace capture. |
| `MCRS_RASTER` | none | Fraction from 0 to 1 for the raster pass. |
| `MCRS_DRAWS` | all | Comma list of draw numbers to keep. |
| `MCRS_SKY` | all | Comma list of sky passes to draw: `disc,twilight,celestial,stars,clouds`. |
| `MCRS_FLY`, `MCRS_TURN` | none | Scripted flight: the player flies forward at a sprint with this flying speed (the default ability is 0.05), and turns round once after `MCRS_TURN` seconds. |
| `MCRS_TIME` | none | Pins every clock to a tick count. |
| `MCRS_POS`, `MCRS_LOOK`, `MCRS_SCREEN`, `MCRS_CURSOR` | none | Start position `x,y,z`, view `yaw,pitch`, a screen to open (`title` by default, `none`, `inventory`, `pause`, `options`, `video` or `accessibility`) and a cursor position, for scripted captures. |
| `MCRS_MENU` | none | Native singleplayer build with `dev` only. Opens a sample container after joining: `generic_9x1` through `generic_9x6`, `generic_3x3` or `hopper`. |
| `MCRS_PLAY` | off | Native build with `dev` only. `1` starts the world folder given as the argument when it belongs to the game directory's `saves` list. |
| `MCRS_CAPTURE` | none | Write one screenshot to a `.png` path and exit. |
| `MCRS_SCREENSHOT_DIR` | none | Directory for screenshots. |
| `MCRS_SCENE_DIR`, `MCRS_SCENE_RECORD` | none | Windowless scene capture directory, and a record of the vanilla client to take entities from. |

The client reads all of these in `crates/mcrs_minecraft_client/src/config.rs`, `dev/knobs.rs` and `scene_capture.rs`.
