The repository has no `good first issue` label yet, so this list is hand-picked. It follows the areas where outside pull requests already landed: the network layer, whitelist and bans, text, and specifications. Of 26 merged outside PRs on 2026-11-09, 6 are network features such as status and transfer, and 6 are specifications from a vanilla server.

Issue states change. Open the issue before you start, and check that nobody works on it.

## How to take a task

1. Read the issue and the files it names. Paths in older issues can be stale, so check them against the repository.
2. Comment on the issue that you take it. State your role: author or implementer.
3. Build and test as on [Build and test](/docs/en/contributing/build-and-test/).
4. Open a PR that links the issue. Update docs in the same PR if a page of this site describes the changed behavior.
5. Ask in [Discord](https://discord.gg/ged3nMRzwG) if you are stuck for more than a day.

Not on the list, but welcome: documentation and translation of this site, see [Write these docs](/docs/en/contributing/docs/). To find more issues, filter by area, for example [`area:network`](https://github.com/andreypfau/mcrs/labels/area%3Anetwork) and [`clean-room`](https://github.com/andreypfau/mcrs/labels/clean-room).
