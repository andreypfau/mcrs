This page lists six open issues that fit a first pull request. The repository has no `good first issue` label yet, so the list is hand-picked. It follows the areas where outside pull requests already landed: the network layer, whitelist and bans, text, and specifications. Of 26 merged outside PRs on 2026-11-09, 6 are network features such as status and transfer, and 6 are specifications from a vanilla server.

Issue states change, so open the issue before you start and check that nobody works on it.

## The list

| Issue | Role | Size | What you do |
|---|---|---|---|
| <Status issue={308} /> | implementer | medium | Fix a bug: past 256 packets in the outbound queue, normal and low priority packets are dropped, so a client can keep a wrong block. Write the rule for what may be dropped, merged or delayed, and a slow-client test. |
| <Status issue={295} /> | implementer | small | Typed packets with codecs for cookies, transfer and player chat. Each round-trips through a fixture captured from the game. |
| <Status issue={290} /> | implementer | small | An example that pings a server and prints version, description, player counts and latency, with only the protocol and network crates. |
| <Status issue={293} /> | implementer | medium | An echo chat bot over the network layer, with no Bevy in its tree. It reconnects after a drop. |
| <Status issue={289} /> | implementer | medium | A packet inspector that decodes a recorded session without unknown packets. |
| <Status issue={507} /> | tooling | medium | A report in xtask that lists spec rule IDs no test names. It fails nothing. |

The last column is a short summary of each issue. When the summary and the issue differ, the issue is right.

## How to take a task

1. Read the issue and the files it names. Paths in older issues can be stale, so check them against the repository.
2. Comment on the issue that you take it, and state your role: author or implementer.
3. Build and test as [Build and test](/docs/en/contributing/build-and-test/) describes.
4. Open a PR that links the issue. Update docs in the same PR if a page of this site describes the changed behavior.
5. Ask in [Discord](https://discord.gg/ged3nMRzwG) if you are stuck for more than a day.

Documentation and translation of this site are not on the list, but they are welcome too, and [Write these docs](/docs/en/contributing/docs/) tells you how to start. To find more issues, filter by a label such as [`area:network`](https://github.com/andreypfau/mcrs/labels/area%3Anetwork) or [`clean-room`](https://github.com/andreypfau/mcrs/labels/clean-room).
