This page shows what mcrs does and what it does not do yet, area by area. It is the only full status table in the docs, and other pages show a part of it. Each row has a date and either a check you can run or a section of PERF.md.

## What the states mean

| State | Meaning |
|---|---|
| <Status state="works" /> | A test you can run or a measurement in PERF.md shows it |
| <Status state="partial" /> | Part works, and the rest is in an issue or a PR |
| <Status state="wip" /> | It is not in the code or not finished, and an issue tracks it |
| <Status state="undecided" /> | No decision yet. The plugin loader (jar, wasm, scripts) is in this state |
| <Status state="declined" /> | A closed decision says no |

<Aside type="note" title="Planned is a direction">
An issue that says "planned" states a direction. It has no date and it is not a promise. The state of an issue also does not tell you the state of the code. A closed issue does not always mean done, and some features are partly in the code while their issue is still open.
</Aside>

Performance numbers are in [PERF.md](https://github.com/andreypfau/mcrs/blob/main/PERF.md), each with the machine and the scenario. All of them were measured on one machine, an Apple M4 Max with macOS. We publish no comparison with vanilla, Paper or other servers.

## What is not planned

- Support for older game versions. mcrs targets one version at a time (<Status issue={412} />).
- Datafixers. A save is read at exactly the targeted data version, and an unknown field is a loud error (<Status issue={388} />).
- A facade or a Bukkit-like API crate (<Status issue={437} />). This decision covers only the facade. A plugin loader for jar, wasm or scripts has no decision yet.

## How to follow progress

You do not need to read code to follow the project.

- All the work is visible in [the GitHub repository](https://github.com/andreypfau/mcrs).
- To follow one issue, open it from the table and press Watch on the right. You need a GitHub account, and you get a mail when the issue changes.
- The [latest code changes](https://github.com/andreypfau/mcrs/commits/main) and the [releases](https://github.com/andreypfau/mcrs/releases) are on GitHub too.
- Questions and progress reports are on [Discord](https://discord.gg/ged3nMRzwG).
- Three issues hold the direction: <Status issue={180} /> for the library, <Status issue={181} /> for many nodes and <Status issue={182} /> for gameplay.
- Decisions and their reasons are the issues with the label [`decision`](https://github.com/andreypfau/mcrs/issues?q=label%3Adecision).

We check this page by hand once a month and on every new tag.
