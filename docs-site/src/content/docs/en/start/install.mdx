## What you need

- Rust through [rustup](https://rustup.rs). You do not pick a version: [`rust-toolchain.toml`](https://github.com/andreypfau/mcrs/blob/main/rust-toolchain.toml) pins `nightly-2026-09-02` and rustup downloads it on the first `cargo` call. It also adds rustfmt, clippy and the wasm32 targets.
- An IDE: RustRover, or IntelliJ IDEA with the Rust plugin. Open the repository root as a Cargo project. Check the current licence terms of RustRover yourself.
- The official client jar of the snapshot. You do not download it by hand: it is taken from the launcher folder, or downloaded from Mojang on first run into the same folder, and checked by SHA-1.
- Java is not needed to run mcrs. Some tools (`tools/vanilla-oracle`, the mob bench) need Java 21 or newer.
- An operating system: the author measured and ran everything on macOS (Apple M4 Max, Metal). CI runs lint, clippy, portability checks and tests on Ubuntu 24.04, without the crates that need a GPU. Windows has a jar path in the code and nobody has checked it.

How long the first build takes and how much disk it needs: not measured yet. The workspace has 122 crates, so expect a long first build.

## Cargo for people who know Gradle

| Gradle | Cargo |
|---|---|
| `settings.gradle` with subprojects | Root `Cargo.toml` with `[workspace]`. The 122 members are in `crates/` |
| `build.gradle` of a project | `Cargo.toml` of a crate |
| `./gradlew run` | `cargo run`. For mcrs add `--release`, a debug build is too slow |
| `./gradlew build` | `cargo build` |
| `./gradlew test` | `cargo test`. This repository uses `cargo nextest run` |
| Gradle wrapper pins the Gradle version | `rust-toolchain.toml` pins the compiler |
| `build/` folder | `target/` folder |
| Maven coordinates and a version | A crate name and a version, or a git URL with `rev` |
| Lock file of dependencies | `Cargo.lock`, committed |
| `implementation` and `api` scopes | `[dependencies]`; there is no `api` scope, all `pub` items are visible |

Crates are not published on crates.io (<Status issue={321} />). So your own code today lives in a clone of the repository, or depends on a git commit.
