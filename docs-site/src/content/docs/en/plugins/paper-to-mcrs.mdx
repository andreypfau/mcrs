Use this page as a lookup: find the Paper, Velocity or Minestom word you know and see what is nearest in mcrs. If "entity" and "system" are new words, read [From objects to data](/docs/en/plugins/mental-model/).

<Aside type="caution" title="Analog, not replacement">
Every row is an analogy. mcrs has no Bukkit-like API, see [This is not the Paper API](/docs/en/plugins/not-paper/). A row marked wip describes a planned feature that is described in an issue and is not in the code yet. A row marked undecided has no issue and no decision.
</Aside>

## Life cycle

| JVM | mcrs | State | Notes |
|---|---|---|---|
| `JavaPlugin`, `onEnable` | `impl Plugin for X` with `fn build(&self, app: &mut App)` | <Status issue={279} state="works" /> | Like Minestom: you write your own `main` ([src/main.rs](https://github.com/andreypfau/mcrs/blob/main/src/main.rs)). No `plugin.yml`, no separate jar |
| `onDisable` | No hook. Shutdown goes through a `ShutdownRequest` message | <Status state="partial" doc="crates/mcrs_minecraft_engine_server/src/shutdown.rs" /> | The embedder writes the request, no signal handler is installed |
| `depend:` and `softdepend:` | A plugin group: a member that needs another fails in `build` and names the missing one | <Status issue={279} state="works" /> | See `MinecraftServerPlugins` in [lib.rs](https://github.com/andreypfau/mcrs/blob/main/crates/mcrs_minecraft_server/src/lib.rs) |
| Disabling a bundled feature | `server.disable::<SomePlugin>()` on the plugin group | <Status issue={282} state="works" /> | Used in [`main.rs`](https://github.com/andreypfau/mcrs/blob/main/src/main.rs) to switch the mob brain off |
| `/reload`, PlugMan | None. Code is not reloaded | <Status issue={316} state="wip" /> | Only data pack reload is planned |
| NMS, CraftBukkit | Any public crate of the library layers | <Status issue={437} state="declined" /> | No facade between you and the engine. It is NMS and API at once |
| Static `Bukkit.getServer()` | None. Take `Res<T>`, `Query<..>`, `Commands` as system parameters | <Status issue={437} state="declined" /> | The static accessor was rejected |
| Dependency on `paper-api` | A git dependency on mcrs crates | <Status issue={321} state="undecided" /> | One game version at a time, no backward compatibility (<Status issue={412} state="declined" />) |

## Events

| JVM | mcrs | State | Notes |
|---|---|---|---|
| `Listener`, `@EventHandler` | An observer `app.add_observer(f)` with `f: fn(On<Event>)`, or `MessageReader<M>` for a message buffer | <Status issue={283} state="partial" /> | Public events exist only for chat. Packet observers exist as `Received<P>` |
| `setCancelled(true)` | The `cancelled` field of the event, set in an observer that takes `mut` | <Status pr={636} state="partial" /> | Only `PlayerChatEvent`. A general mechanism with rollback of client prediction is <Status issue={283} state="partial" /> |
| `AsyncChatEvent` | `PlayerChatEvent { player, text, cancelled }` | <Status pr={636} state="works" /> | `text` is a `Text` component, not a `String`. It fires before the broadcast |
| `EventPriority` | System order: `.before()`, `.after()`, `SystemSet` such as `TickSet` | <Status issue={323} state="works" /> | Observers have no priority. An unordered conflict fails a test |
| `PlayerJoinEvent`, `PlayerQuitEvent` | Internal bus messages `InboundPlayerSpawn` and `InboundPlayerDespawn` | <Status issue={283} state="partial" /> | Not a public event yet, join and leave are planned |
| `BlockBreakEvent`, `BlockPlaceEvent` | The message `BlockActionRequest`, internal | <Status issue={283} state="partial" /> | Public cancellable events are planned |
| `ProtocolLib`, packet listeners | `On<Received<P>>` over the typed game packets | <Status state="partial" /> | About half of the packets are typed, see the README. One typed receive path: <Status issue={57} state="partial" /> |
| Minestom `EventNode` tree | No event tree, only Bevy observers and schedules | <Status state="undecided" /> | No issue, do not copy the pattern |

## Scheduler

| JVM | mcrs | State | Notes |
|---|---|---|---|
| `runTaskTimer` | A system in `FixedUpdate`, 20 ticks per second by default (`DEFAULT_TPS`) | <Status state="works" doc="crates/mcrs_minecraft_engine_server/src/runner.rs" /> | State in a resource or `Local<T>`. Scheduling is Bevy's, mcrs has no scheduler of its own |
| `runTaskLater` | A counter or timer in a resource or component, or `Res<Time<Fixed>>` | <Status state="works" /> | By hand, no helpers |
| `runTask` to return to the main thread | Not needed. There is no main thread in the Bukkit sense | <Status issue={357} state="works" /> | See [From objects to data](/docs/en/plugins/mental-model/) |
| `runTaskAsynchronously` | Bevy task pools exist, but there is no documented pattern for plugins | <Status state="partial" /> | No issue. Parallelism comes from the scheduler |

## Players and worlds

| JVM | mcrs | State | Notes |
|---|---|---|---|
| `Player`, `Entity` as objects | An `Entity` id plus components `Player`, `GameProfile`, `PlayerGameMode`, `Transform` | <Status state="works" doc="crates/mcrs_minecraft_engine/src/ability.rs" /> | There are three ids: the Bevy `Entity`, `PlayerSession` (lives across dimensions), the network id (<Status issue={158} state="wip" />) |
| `player.sendMessage(Component)` | An `OutboundPlayerPacket` message, built with `bus::to` and the `system_chat` helper | <Status state="partial" /> | Low level, no `player.send()`. |
| `Bukkit.getOnlinePlayers()` | `Query<&GameProfile, With<Player>>` inside a dimension | <Status state="partial" /> | Players live in dimension worlds, there is no global collection (see <Status issue={154} state="wip" />) |
| `world.getBlockAt(..).setType(..)` | The `BlockSetRequest` message and the `WorldView` volume API | <Status state="partial" /> | Works inside one dimension. "One world-access API": <Status issue={486} state="partial" /> |
| `World` and `createWorld` for mini games | Dimension worlds are fixed at start | <Status issue={546} state="wip" /> | Create and remove at run time is planned |
| Minestom `Instance` | A dimension world (a sub-app) | <Status issue={280} state="works" /> | Add plugins with `add_dimension_plugin`, not `add_plugins` |
| `ChunkGenerator` | A replaceable chunk source | <Status issue={281} state="wip" /> | Today the generator is the vanilla one |
| Saving the world, `world.save()` | None. Reading Anvil works, writing does not | <Status issue={78} state="wip" /> | The server does not save chunks |
| Boss bar | None | <Status issue={247} state="wip" /> | |
| Scoreboard | None. Only the planned owner of global state names scoreboards | <Status issue={154} state="wip" /> | No scoreboard issue, no code found |
