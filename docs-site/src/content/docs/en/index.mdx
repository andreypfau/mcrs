mcrs is Minecraft Java Edition written in Rust on Bevy ECS: a server, a client and 122 crates they are built from.

<Aside type="caution" title="Early WIP">
The project is in active development, so a lot is missing: world saving, online mode, most of the gameplay. The world and the client already run.
</Aside>

## Why mcrs

mcrs is not the Java server rewritten in Rust. It decides from scratch how the game should be built, starting with the engine. Read [Why mcrs: a new design, not a rewrite](/docs/en/start/philosophy/).
