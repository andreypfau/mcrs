mcrs is Minecraft Java Edition written in Rust on Bevy ECS. It is a server, a client and the {fact('crates')} crates they are built from.

<Aside type="caution" title="Early WIP">
The project is in active development and a lot is missing, including online mode and most of the gameplay. The world and the client already run.
</Aside>

## Why mcrs

mcrs is not the Java server rewritten in Rust. It decides from scratch how the game should be built, and it starts with the engine. The page [Why mcrs: a new design, not a rewrite](/docs/en/start/philosophy/) explains each choice.

## Where the project stands

World generation matches the real game on reference dumps, and the client renders that world. The server saves changed chunks to region files, and there is no online mode.[^82] We checked this on 2026-11-10 at commit `3540f457b`, against game snapshot {fact('snapshot')}. The [Status](/docs/en/start/status/) page has the full table.

You can ask questions and read progress reports on [Discord](https://discord.gg/ged3nMRzwG).

[^82]: <Status issue={82} /> Tracks online mode: encryption and session authentication.
